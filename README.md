# RishtaRent

RishtaRent is a simulated website where families book a rishta aunty for a home visit in Islamabad and Rawalpindi. The app shows the full price before booking, and no real aunty or payment is involved.

## Commands

```
npm install
npm run dev      # start the dev server
npm run build    # build to dist/
npm run lint     # run oxlint
npm run preview  # serve the built dist/
npm test         # run the rule tests
```
